# 一页纸打成了二十份

这是一个虚构示例，用来演示从口播稿走到逐句分镜。

## 口播稿

我就想打印一张清单，点完才发现，份数填了二十。

第一张出来的时候，我还拿起来看了看，挺清楚。

然后第二张、第三张，一模一样。我这才反应过来，它是真打算给我打二十份。

我赶紧去点取消。等它停下来，桌上已经有八张清单了。

现在家里谁找不到购物清单，我就给他发一张新的。

## 分镜草案

| 图号 | 触发词 | 画面 |
| --- | --- | --- |
| 01 | 二十 | 主角刚点打印，光标旁边的份数框显示 20。 |
| 02 | 第一张 | 主角手上只有一张清单，打印机与桌面位置固定。 |
| 03 | 第二张、第三张 | 出纸口继续出纸，主角转头看机器。 |
| 04 | 八张 | 按取消后画面切到桌上的一叠纸，字幕读到数量时再标出八份。 |
| 05 | 发一张 | 主角从同一叠纸上抽出一张递出去，收尾。 |

画面从已选旁白定位。正式出图前补角色参考与画幅，然后核对五张图的打印机、桌面、纸张以及主角服装是否相同。

## 配音和剪辑交接示意

| 工序 | 这集怎么执行 |
| --- | --- |
| 试读 | 先读第一句及「第二张、第三张」，试听数字有没有抢读，第一张和连续出纸的语气是否有变化。 |
| 出图 | 统一人物服装、打印机朝向和桌面位置。先准备点打印、只出一张、纸叠变厚三个状态。 |
| 对齐 | 选定旁白后把第 03 镜入点对到「然后第二张」。第 04 镜在「按取消」后看到停止，在「八张」时再显示数量。 |
| 混音 | 在连续出纸时加轻短的进纸声，保留「第二张、第三张」的人声清晰度。 |
| 复看 | 连看第 02 到第 04 镜，确认纸的数量顺着台词变化。听最后一句是否完整，再接片尾。 |

示例以原声触发词演示交接。实际配音录制后，在 [分镜表](../skills/xudatou-handdrawn-video/templates/shot-list.csv) 记录入点和出点。

## 封面与发布文案示例

- 发布标题　我就想打一张购物清单
- 封面上方　份数忘了改
- 封面主标题　一页打了二十份
- 主体　打印机正在往外吐纸，主角一只手伸向取消按钮。4:3 保留手和打印机，3:4 放大出纸口、手和表情。
- 发布文案　按下取消的时候，打印机已经替我做了八份。
