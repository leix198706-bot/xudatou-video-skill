# 徐大头手绘短视频制作方法

## 先核对手上的材料

- 确定本轮交付阶段和画幅。续作先看创作者最后保存的稿件、实际采用的旁白和画面、手动改过的原生工程。
- 新片先明确一件具体的事、一位叙述者和一个值得观众看完的后果。口播用日常聊天的语气，读顺后再锁稿。已锁定内容如需调整，另存建议版本。

## 检查人物项目素材

开始新人物项目，或将要出图、配音、包装时，先检查用户指定的素材目录。默认用当前视频项目下的 `人物项目/`。按 [人物项目素材与检查](references/project-assets.md) 运行随附脚本，再核对当前工序真正需要的素材。出图核对角色参考，配音核对音色，品牌包装核对相应品牌图。

- 缺人物参考时，主动告诉用户先制作一张角色基准图，或请他提供已有角色参考。缺音色时，提示先录一段干净样音，或从有权使用的预设音色中选定一个。
- 缺项时继续交付用户已授权的选题、稿件或文字分镜。涉及缺项的出图、配音等待对应素材，或按用户授权先制作该素材。
- 水印、片尾和封面参考按本次用途提示。续作优先核对原生工程实际采用的素材和已经确认的配音。
- 使用用户选定且当前可用的出图、配音和剪辑工具。工具缺失时，把当前能完成的交接材料交齐，按实际结果标记阶段。

## 按阶段制作

| 阶段 | 做法与交付 |
| --- | --- |
| 选题与写稿 | 从具体动作或反差开口，每段推进一个动作、结果或情绪变化，结尾收一次。交选题卡或可朗读的完整正文。见 [选题与文案](references/story.md)。 |
| 旁白与分镜 | 用核定的稿件和可授权使用的声音。按最终原声给画面、字幕、道具和音效定触发点。尚未配音时先记录逐句关系。见 [画面与连续性](references/visual.md) 和 [配音、剪辑与验收](references/production.md)。 |
| 镜头出图 | 用一张角色基准锁定身份，服装、空间与道具随场景延续。先用少量代表镜头检查画风，再按本轮授权推进。按图号展示当前版本和对应台词。见 [画面与连续性](references/visual.md)。 |
| 剪辑与导出 | 以最新旁白为时间基准，画面到句再切。字幕、音乐、音效、水印各自分轨。续作先备份实际使用的原生工程，导出后查看实物。见 [配音、剪辑与验收](references/production.md)。 |
| 封面与发布包装 | 标题、短文案和标签以当前成片为依据。封面按目标比例独立构图，核对缩略图和像素。见 [封面与发布包装](references/covers.md)。 |

用 [单集制作卡](references/episode-template.md) 记录当前采用的文件版本，并分别更新技术检查、用户看图或试听、原生导出、平台发布的状态。平台发布需用户明确授权。
