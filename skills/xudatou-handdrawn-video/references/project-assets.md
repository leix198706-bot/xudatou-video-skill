# 人物项目素材与检查

每个创作者在自己的视频项目中管理人物和音色，可以指定一个已有的目录。新建可用这个结构：

```text
人物项目/
├── 人物参考/            基准图，按需加三视图、表情和服装
├── 音色/                经授权的旁白参考音频
└── 品牌素材/
    ├── 水印/
    ├── 片尾/
    └── 封面参考/
```

用 Python 3 运行 [check_assets.py](../scripts/check_assets.py)。命令中的脚本路径以当前安装位置为准，位置参数是**人物项目目录**。省略该参数时，检查当前工作目录下的 `人物项目/`。脚本检查文件可读性、扩展名与基本格式标识。复用任意已有文件布局时，用 `--character` 和 `--voice` 指定相应文件：

```sh
python3 /技能安装目录/scripts/check_assets.py "/自己的项目/人物项目" \
  --character "现有基准图.png" --voice "现有样音.wav"
```

两个文件选项接受绝对路径或相对人物项目的路径。脚本返回 `0` 表示找到了人物参考和音色文件，返回 `1` 表示至少缺少其中一项。人物参考支持 PNG、JPG、JPEG、WebP。音色支持 WAV、MP3、M4A、AAC、FLAC、OGG、Opus。品牌水印检查 PNG，片尾另支持 MP4 与 MOV。

文件检查通过后，实际打开人物图并试听样音，确认媒体能解码、身份相符，且创作者有权使用。文件头检查只用于初筛。已确认的预设音色可以从所用平台核对名称、试听结果与可用性。没有 Python 时，手动执行同一检查。

## 缺素材时怎么提示

- **人物参考**　先整理脸型、发型、衣着与用色，做一张清晰的正面全身基准图。基准图写清轮廓、头身比例和主要配色。需要多个角度或情绪时，以确认的基准图补做三视图与表情。使用创作者选定的出图工具并复核同一身份。
- **音色**　请创作者提供一段安静环境下的清晰旁白样音，或选定有权使用的预设音色。选一小段包含普通叙述、专名和情绪变化的本集台词试听。记录选用的声音与试听结果。续作可直接核对已确认的成品旁白。
- **品牌素材**　做品牌包装时准备自己的透明水印、片尾和所需比例的封面参考。

向用户报告实际缺项，再完成本轮能独立交付的文字阶段。例如「这个人物项目还缺人物基准图和旁白音色。可以先做一张角色设定图，再录一段清楚的样音，或者用你已有的图和声音。」
