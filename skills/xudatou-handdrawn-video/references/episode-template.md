# 单集制作卡

每集把制作卡、当前稿和分镜放在同一主题目录。并行制作的多集可共用同一人物项目。续作沿用作者已有的文件结构，在制作卡里引用实际采用版本。

| 字段 | 本集内容 |

| 本轮范围与目标画幅 |  |
| 事实、创作者自述或演示案例的来源 |  |
| 当前稿件与确认记录 |  |
| 角色、服装、空间、道具及品牌图参考 |  |
| 已采用旁白、实测时长及试听状态 |  |
| 原生工程位置、备份和实际引用的图 |  |
| 成片、发布标题与封面候选文件 |  |
| 技术检查、创作者视听确认、平台发布状态 |  |
